#  Space Dodger

A browser-based arcade game where players dodge asteroids and survive as long as possible.

## 🔗 Live Demo

https://richardweb1.github.io/space-dodger/

##  Features

* Smooth gameplay only on desktop 
* Score tracking and high score
* Wallet connection Uses GenLayer testnet (GEN faucet) for safe non-financial testing
* On-chain score submission (demo)

##  GenLayer Concept

This project explores integrating GenLayer as an AI powered trust layer for gaming.

GenLayer can be used to:

* Verify leaderboard scores
* Resolve disputes between players
* Enforce challenge-based game contracts

This is a testnet prototype no real money involved, demonstrating how AI based validation and decentralized decision making can improve fairness in games.
